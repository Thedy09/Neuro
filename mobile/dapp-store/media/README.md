# dApp Store media assets

Drop the assets referenced by [`../config.yaml`](../config.yaml) here:

- `icon.png` — 512×512 app icon.
- `screenshot-1.png` … `screenshot-n.png` — 1080×1920 portrait device captures
  (3–8 recommended).

These are uploaded when you run `npx dapp-store create release`. See
[`docs/SOLANA_DAPP_STORE.md`](../../../docs/SOLANA_DAPP_STORE.md).
